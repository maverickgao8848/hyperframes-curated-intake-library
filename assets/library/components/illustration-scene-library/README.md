# illustration-scene-library

Unified selector for the same six frozen Open Peeps chapter-cover assets.

- `sceneId`: thinking, co-create, prompt, retrieval, analytics, or launch.
- `title`: chapter title.
- `chapterIndex`: visible 1-99 chapter index.
- `sceneVariant`: must identify one of the same six frozen scenes.
- `focalSide`: `left` or `right`.
- `density`: sparse, comfortable, or dense.
- `caption`: short chapter promise.
- `accentRole`: semantic accent role.
- `durationFrames`: deterministic seek window.

This selector does not create a seventh illustration and is not eligible for
body evidence Frames. Ferrari and Lamborghini directions explicitly fall back
to `icon-lucide-set` when the illustration language is unsuitable.
