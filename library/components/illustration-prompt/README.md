# illustration-prompt

Prompt and terminal chapter cover; chapter-cover use only.

- `title`: chapter title.
- `chapterIndex`: visible 1-99 chapter index.
- `sceneVariant`: fixed to `prompt`.
- `focalSide`: `left` or `right`.
- `density`: sparse, comfortable, or dense.
- `caption`: short chapter promise.
- `accentRole`: semantic accent role.
- `durationFrames`: deterministic seek window.

This component uses one frozen Open Peeps CC0 SVG from the six-asset scene
library. It is not eligible for body evidence Frames. Ferrari and Lamborghini
directions explicitly fall back to `icon-lucide-set` when the illustration
language is unsuitable.
