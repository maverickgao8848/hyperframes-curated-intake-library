# Intake and approval

Inspect the complete source, prior approvals, project state, Frame candidates, catalog and local
media before asking questions. Summarize what is already known and ask one compact batch only for
unresolved delivery facts, source scope, exact Frame, animation-worthy passages/scenes, required
assets and rights, user visual ideas, exclusions, and curation policy.

Apply the v3 authoring contract from [storyboard-authoring.md](storyboard-authoring.md) to creative
details the user leaves open. Reserve a second question batch for contradictions or facts that
materially block an accurate handoff.

## Shared-creative review

Present the complete proposed sequence before writing canonical files. Each scene card shows its
stable ID and numeric window, source anchor when evidence requires it, content, visual, motion,
approved uses, optional transition semantics, and any field locks. Keep candidates and rejection
rationale in a separate curation view; they never enter the approved Storyboard.

Ask for one explicit approval of the Frame, animated-scene set, complete scene concepts, and their
handoffs. Stable scene IDs begin at approval. `next` is optional for ordinary hard cuts, otherwise
targets only the adjacent scene, and is always absent on the final scene.

## Routed intake

Validate the parent plan hash and segment IDs before questions. Restate inherited scope, locks,
Frame/visual policy, timing, assets, and open questions. Do not repeat the whole-film interview or
change non-cluster decisions. Review only the requested cluster. Return any scope expansion as a
proposal; it never mutates the parent plan.
