# Collaboration mode and asset direction

- `hands-off`: use existing sources, verified catalog items, and explicit fallbacks; request only indispensable assets.
- `cooperative`: request a small number of high-value additions with clear examples and specifications.
- `director-led`: assign who captures what, angle, light, duration, format, deadline/status, intended segment, and layers. Keep the language direct and respectful and always include a fallback.

Every asset request records priority (`required`, `recommended`, `optional`), source/owner, exact specification, segment IDs, status, and fallback. External evidence also records the claim it supports and must never be fabricated.
