# Handoff v3

`HANDOFF.md` is a short launch page, not a second director contract. It contains only status, schema,
project, the three canonical inputs (`BRIEF.md`, `frame.md`, `STORYBOARD.md`), manifest path,
preflight state, next action, and blockers.

Do not include scene tables, scene titles, catalog IDs, component/action/transition copies, creative
defaults, build protocol prose, or a copy-ready prompt. The later `$hyperframes` run reads the three
canonical files and `.hyperframes/intake-manifest.json`.
